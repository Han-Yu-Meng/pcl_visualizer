3 · 辅助平面（重点）

平面用于对照地面是否水平、墙面是否竖直。可用「拟合附近点」让平面自动贴合点云，再读出偏离理想方向的角度。

「偏差着色」只对 ±色标 范围内的点上色，超出范围的点显示为半透明深灰（可用「外部点不透明度」调整）；默认 ±0.1 m，绿=共面。剖面厚度 > 0 时只显示距分析平面 ±厚度 内的点，便于观察该处点是否共面。

4 · 辅助线

选择一种模式后，在视图中点击分析平面即可在该点放置辅助线。

使用说明

操作：左键拖动旋转，右键拖动平移，滚轮缩放；鼠标悬停可读取平面上的坐标与到平面的距离。

快捷键： 1 等轴 / 2 俯视 / 3 前视 / 4 侧视 / R 重置 / F 拟合当前平面 / C 切换剖面。

判断方法：把水平面放到地面附近 → 点「拟合附近点」→ 看「偏离基准角度」；再把竖直面贴到墙面拟合一次。角度越接近 0° 越横平竖直。着色切到「平面偏差」可看正负偏差分布。

纯 HTML + JS，无后端、无上传；Three.js 通过 CDN 加载。可直接部署到 GitHub Pages。
